# Service

A Go service on [github.com/terraskye/eventsourcing](https://github.com/TerraSkye/eventsourcing),
built slice by slice from an Event Modelers board by the build kit in
`.build-kit/`.

Before the first slice is generated, give the module its real path:

```bash
go mod edit -module github.com/you/your-service
```

## Run it

```bash
go run .          # :8080 (ADDR), SQLite database events.db (DATABASE)
go test ./...
```

## Layout

```
main.go          # the server; yours
wiring.go        # the backend (SQLite); the only backend-specific file; yours
app_gen.go       # registers every slice; regenerated by esgen
events/          # one file per event; regenerated by esgen
slices/<slice>/  # one folder per board slice
automations/     # one folder per automation
.build-kit/      # the build kit: CLAUDE.md, runner prompts, esgen (.build-kit/gen)
```

Generate a slice by hand with `go -C .build-kit/gen run . -slice <folder>`.
